Prototype state is ready: silent mode is off, there are no stale player or say processes, Claude Code is version 2.1.269, and the max thinking tokens variable is not set anywhere in your environment, so the two variants will differ as the probes measured.

Your part now. Open a second terminal and start Claude Code with the prototype plugin. Run the fast variant first, since it is the one the design is leaning toward. The command sets the max thinking tokens variable to zero and points to the prototype plugin directory on your desktop.

Then, if you have the patience, run one more time without that environment variable for item one only, to feel the thinking delay.

Ask something that produces a long response with a code block, a table, and a list, and work through this checklist. Jot a line per item and paste them back here; the timings will be pulled from the log.

First, type the read aloud command when the response lands and note the rough seconds to speech. Does the script sound like a person talking? How did it handle the code, table, and list? Any dead air between paragraphs?

Second, check what shows while the fork runs and when it finishes: a tasks footer hint, a task row, a relayed reading started line? Is that acceptable as the one-line notice?

Third, mid-reading, type the read aloud stop command. How does the blocked expansion render, plain line or error banner? Did speech stop within a second? Did anything land in the conversation?

Fourth, mid-reading, type the read aloud command again. Was there a clean handover to the new reading? Fifth, test the control verbs: read aloud status, read aloud auto on, and read aloud auto off. Note the rendering only.

Sixth, type read aloud brief on a long response, then read aloud show to see a script on screen. Seventh, type the read aloud command the instant a response lands. Did it read the new one or the previous one?

Eighth, exit Claude Code while speech plays. The expected result is that speech continues. Ninth, what is your gut verdict? Would you leave this on? What would make you turn it off?

Do not run reset afterwards; the log is needed intact to report the timings.
