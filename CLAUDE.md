# claude-read-aloud

Claude Code plugin that reads the last response aloud via text-to-speech.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`rileybroberts/claude-read-aloud`), driven via the `gh` CLI. The wayfinder design map is the issue labelled `wayfinder:map`; its tickets are sub-issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` at the root for the glossary, `docs/adr/` for decisions. See `docs/agents/domain.md`.
