# claude-read-aloud

A Claude Code plugin that reads the last response aloud via text-to-speech, so long answers don't turn into a wall of text your brain tunes out.

**Status: design phase.** The design lives on the [Read Aloud v1 design map](https://github.com/rileybroberts/claude-read-aloud/issues/1) (GitHub issue labelled `wayfinder:map`). Its tickets are the map's sub-issues; open, unblocked, unassigned ones are the frontier. Vocabulary is in [`CONTEXT.md`](./CONTEXT.md).

To work the next ticket in a Claude Code session, run `/mattpocock-skills:wayfinder 1` from this repo.
